# BMAD-METHOD

## What it is

"Agile AI Driven Development (AiDD)": an encoded delivery methodology — Clarify → Plan →
Build & verify → Learn, with specialized role perspectives (product, architecture, UX,
dev, testing) — installed as skills into the user's harness via `npx bmad-method install`.
V6 pitches "right-sized process": small changes go straight to build, complex work gets
the full planning depth. Ships a module ecosystem in separate repos (Builder, Creative
Intelligence Suite, Test Architect, Loop — unattended epic execution, Game Dev Studio).
52k stars in ~16 months. (README + installer source at the pin; workflow content unread.)
