# System Card: Claude Sonnet 5

146 pages, dated June 30 2026. Self-contained for the model in its title, like the
[Opus 5 card](2026-claude-opus-5.md) and unlike Gemini's thin delegating cards.

## The finding: it states no cutoff, and its sibling does

**Zero occurrences of "cutoff" or "cut-off" in 146 pages** (searched 2026-08-26). §1.1
*Training data and process* describes the data's sources and methods and gives no date:

> Claude Sonnet 5 was trained on a proprietary mix of publicly available information from
> the internet, public and private datasets, and synthetic data generated by other models.
> In the course of its training, we used several data cleaning and filtering methods,
> including deduplication and classification. We use a general-purpose web crawler called
> ClaudeBot to obtain training data from public websites…

The [Opus 5 card](2026-claude-opus-5.md), same vendor, same genre, same §1.1 heading,
published three weeks later, *does* state one: *"Claude Opus 5's knowledge cutoff date is
May 2026."*

**So an Anthropic system card is not a reliable cutoff surface — the docs table is.**
`docs.claude.com`'s models overview carries `reliableKnowledgeCutoff` and
`trainingDataCutoff` for every model as structured data; the cards state it when they feel
like it. That refines the surfaces guidance recorded earlier the same day, which had the
split as "cards for depth, docs for specs" per vendor: within Anthropic, the cards are
*additionally* inconsistent about specs.

Sonnet 5's recorded cutoff (2026-01, `vendor-stated`) comes from the docs table and is
unaffected — this card neither corroborates nor contradicts it.

## Open questions

- Is the omission editorial or does it track something? Opus 5's card is 198 pp to Sonnet's
  146, and the cutoffs differ (2026-05 vs 2026-01). One instance each way is not a pattern;
  a third card would make it one.
- 146 pages unread beyond §1.1 — evaluations and red-team results are where the depth is.
