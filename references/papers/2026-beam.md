# Beyond a Million Tokens: Benchmarking and Enhancing Long-Term Memory in LLMs (BEAM)

`retrieved: 2026-08-18` · `read_depth: full` · [ICLR 2026 / repo](https://github.com/mohammadtavakoli78/BEAM)

## What it does

Two contributions. **BEAM**: 100 fully synthetic user–assistant conversations from
100K to 10M tokens, with 2,000 human-validated probing questions over ten memory
abilities — seven inherited from prior work plus three new: instruction following,
event ordering, contradiction resolution (§2.2). **LIGHT**: a cognitive-science-styled
memory framework (episodic vector index + working memory + iteratively summarized
scratchpad) that improves backbone LLMs by 3.5–12.69% average over their best
baseline (§3–4).

## Design

- **Generation is plan-first**: LLM-generated conversation plans (domain, narratives,
  MBTI-sampled user profile, relationship graph, timeline) recursively decomposed
  into sub-plans and bullet points; user turns from LLaMA-3.3-70B, assistant turns
  role-played with question-detection and follow-up modules; 10M-token conversations
  stitch ten interlocking plans (§2.2.1–2.2.3). Everything is synthetic; humans only
  validate the probing questions.
- **Scoring**: nugget evaluation — annotators decompose each ideal answer into atomic
  nuggets; an LLM judge scores each 0/0.5/1 and abilities average across nuggets;
  event ordering scored by Kendall tau-b over LLM-aligned event sequences (§2.4).
  Judge agreement with humans is not reported in the main text (contrast
  LongMemEval's 97% meta-eval).
- **LIGHT** (§3): after each turn, extract key-value pairs into an embedded episodic
  index (bge-small); keep last-z turns as working memory; maintain a scratchpad of
  salient facts, compressed to a 15K summary past a 30K threshold; filter scratchpad
  chunks for query relevance at answer time.

## Numbers worth keeping

- Baseline averages are **low**: at 100K, vanilla long-context models average
  0.19–0.28, RAG 0.21–0.31, LIGHT 0.29–0.36 (Table 1). At 10M, best averages are
  0.22–0.27. The instrument has enormous headroom — it discriminates.
- All methods strongest on **abstention**, weakest on **contradiction resolution**
  (§4.2) — the ability the memory kind's lint/feedback loops (ai-memory's
  `memory_lint` contradiction findings) target.
- LIGHT gains grow with length: +49.1% (Llama-4-Maverick) at 100K → +155.7% at 10M
  over long-context baselines (§4.2). Scratchpad is the most valuable component in
  ablation; working-memory removal sometimes *helps* at 500K–1M (Figure 3).
- Retrieval budget sweet spot K=15; K=20 degrades — noise, not recall, binds (Figure 4).

## What it means for this repo

This is the instrument behind cognee's headline numbers (`Cognee on BEAM` report at
our cognee pin: **0.79** at 100K, **0.67** at 10M — the report itself flags the 10M
figure as in-sample/exploratory). Two catalog-grade cautions: (1) the paper's own
best configurations average **~0.36 at 100K** — a vendor 0.79 implies a materially
different eval slice, judge, or rubric application, so the comparison across reports
is not apples-to-apples until someone reconciles configs (cognee's report says it
used "BEAM's rubric-based evaluation logic" but tuned prompts/retrieval per scale);
(2) generation and judging are both LLM-run end to end — nugget validation is the
only human touchpoint. Beyond vendor-grading: LIGHT's episodic-index + scratchpad +
working-memory decomposition is the third independent map (after LongMemEval's CP1–4
and the arc's source reads) that converges on the same mechanism set the memory kind
ships — ai-memory's `_slots/` are a scratchpad, its tiers are episodic policy; memos'
L1 traces are the episodic index. The convergence itself is a finding: academia and
vendors are building the same three memories under different names. And again: the
domain is personal-life conversation — the paper's own coding mention ("coding
domains generally require fewer turns", §2.2.1) concerns token budgeting, not
evaluation. No coding-agent memory instrument exists in this set.

## Limits

- Fully synthetic conversations (plans, turns, follow-ups all LLM-generated); human
  validation covers probing questions only. Narrative coherence is claimed, not
  independently measured.
- LLM judge without reported human-agreement meta-evaluation in the main text.
- 100 conversations / 2,000 questions; per-ability-per-length cells get thin.
- LIGHT is the benchmark authors' own method evaluated on their own benchmark — the
  usual instrument-maker/method-maker coupling; treat the improvement magnitudes as
  upper-bounded by construction familiarity.
