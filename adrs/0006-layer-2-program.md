# ADR-0006 — Framework code-outcome A/Bs stop; the bundle becomes the subject

`decided: 2026-08-18` · `recorded: 2026-08-18 (backfill)` · status: **accepted**

## Decision

After exp-03's two-tier result, the repo stops benchmarking workflow frameworks on
code outcomes. The measurement program pivots to the model+harness **bundle** (harness
A/Bs, the variance atlas, the throughput arm) plus artifact-level framework value.

## Context and record

This decision's full argument — four evidence strands, three measurement tracks,
stated falsifiers that would reopen framework A/Bs — is the dated position note
[`notes/cross-cutting/layer-2-program.md`](../notes/cross-cutting/layer-2-program.md)
(the harness layer's number, 2, is unchanged by ADR-0007, so the note's name and
content read correctly under both numberings). Promoted as README conclusion 12;
backlog in [issue #17](https://github.com/leandromineti/ai-assisted-coding/issues/17).

## Consequences

Experiments 01–03 close the framework-measurement arc; the rig's next subjects are
harnesses and tiers, not frameworks.
